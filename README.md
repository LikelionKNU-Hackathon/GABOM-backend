# GABOM Backend

가봄(GABOM)은 지역 가게 방문에 스탬프와 보상 요소를 더해  
사용자의 지속적인 지역 상권 이용을 돕는 서비스입니다.

사용자는 주변 가게를 탐색하고 방문 인증을 통해 스탬프를 모을 수 있으며,  
점주는 방문객이 작성한 리뷰를 바탕으로 가게에 대한 분석 결과를 확인할 수 있습니다.

## 주요 기능

### 사용자 기능

- 회원가입 및 JWT 기반 로그인
- 지역 가게 검색 및 상세 정보 조회
- 가게별 리뷰 작성 및 조회
- 방문 인증을 통한 카테고리별 스탬프 적립
- 스탬프 개수에 따른 티어·칭호·랭킹 확인
- 보유 스탬프를 사용한 리워드 교환
- AI 챗봇을 활용한 카테고리별 가게 추천

### 점주 기능

- 점주 회원가입 및 사업자 정보 관리
- 가게 리뷰의 긍정·부정 비율 확인
- 같은 업종의 다른 가게와 리뷰 항목 비교

## 기술 스택

- **Backend:** Java 17, Spring Boot, Spring Security
- **Database:** MariaDB, Spring Data JPA
- **Authentication:** JWT
- **AI:** OpenAI API
- **Build:** Maven
